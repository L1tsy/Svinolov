# 🐷 «Свинолов» (Pig Catcher)

Браузерная 2D-игра в жанре тайкун/кликер на чистом HTML5 Canvas + JavaScript без внешних фреймворков и библиотек.

## 📋 Описание игры
На весёлой ферме свиньи постоянно норовят сбежать из загона! Вы играете за фермера-ловца. Ваша цель — переловить всех сбежавших свинок и вернуть их в амбар. За каждую пойманную свинку фермер получает золотые монеты.

Игра разбита на дни: с каждым новым днем количество сбегающих поросят возрастает, а свинки проявляют характер — спокойно блуждают по лужайке, но в панике бросаются врассыпную, если к ним приближается ловец или курсор/палец!

---

## 🚀 Как запустить
Игра не требует сборки, установки пакетов или веб-сервера.
- Просто откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Safari, Edge, Яндекс.Браузер и др.).
- Прекрасно работает как на **ПК** (управление клавиатурой и мышью), так и на **смартфонах и планшетах** (тач-управление).

---

## 🎮 Управление
- **Клавиатура (ПК)**:
  - **W, A, S, D** или **Стрелочки**: свободное перемещение фермера. При отпускании клавиш фермер **останавливается ровно на месте**.
  - **ЛКМ** (клик в любое место экрана) или **Пробел (Space)**: взмах сачком на круговую область вокруг фермера.
- **Сенсорные экраны (смартфоны и планшеты)**:
  - **Виртуальный D-Pad** (слева внизу): перемещение в 4 направлениях.
  - **Кнопка «Поймать»** (справа внизу) или **Тап по экрану**: взмах сачком на область вокруг.
- **Правило ловли и кулдаун**:
  - Игроку **не нужно кликать по свинье мышкой**.
  - При нажатии ЛКМ или Пробела вокруг фермера возникает кружок действия сачка.
  - Если в кружок попадает свинья — ловится **ровно 1 свинья**.
  - Вторую свинью можно поймать после перезарядки (по умолчанию 1 секунда, отображается индикатором ⏳ над головой).

## ✨ Игровые механики и возможности

### 1. 🛒 Магазин улучшений (Shop)
Открывается по кнопке `🛒 Магазин` в верхней панели:
- **👢 Сапоги-скороходы** (3 уровня): увеличивают скорость бега фермера (`+18%` за уровень).
- **🕸️ Большой сачок** (3 уровня): увеличивает радиус кружка поимки (`+15%` за уровень).
- **⚡ Ловкие руки** (3 уровня): уменьшают время перезарядки между взмахами (с 1.0 с до 0.4 с).

### 2. 🤝 Прогрессивный найм напарников
Начиная с 10-го дня фермер может нанимать автономных помощников-ловцов:
- **1-й напарник**: день **10**, стоимость **50 🪙**;
- **2-й напарник**: день **20**, стоимость **75 🪙**;
- **3-й напарник**: день **30**, стоимость **100 🪙**;
- *Формула*: `Стоимость = 50 + 25 * N`, `День = 10 + 10 * N`.
- Каждый напарник имеет уникальный цвет комбинезона и номер бейджика (`#1`, `#2`...), самостоятельно патрулирует деревню и ловит свиней.

### 3. 👑 Большая свинья (+10 🪙)
- Появляется на **15–20 днях** (крупная свинья с золотой короной).
- В одиночку игрок её поймать **не может** (она вырывается).
- Требуется поимка **вдвоём с напарником** при совместном удержании в упор!
- За поимку даётся щедрая награда: **+10 монет**!

### 4. ⚡ Бонус за быстрый улов
- Если переловить всех свиней дня быстрее целевого времени — начисляется бонус **+3 монеты** (`⚡ БЫСТРЫЙ УЛОВ`).

### 5. 🗺️ Расширение карты деревни и камера (с 20-го дня)
- Начиная с 20-го дня игровой мир расширяется в **1.6 раза**.
- Включается **виртуальная камера**, плавно следующая за фермером.
- Появляются новые живописные зоны:
  - 🍎 **Яблоневый сад** на севере;
  - 🎃 **Тыквенный огород** на юго-западе;
  - 🦆 **Пруд с кувшинками** на юго-востоке.
- В правом нижнем углу экрана активируется **радар-миникарта**, отображающая перемещение всех свиней, напарников, амбара и игрока в реальном времени.

### 6. 🏠 База и деревня
- Амбар расположен по центру карты. Пойманные свинки возвращаются в амбар.
- Вокруг амбара построена уютная деревня: дом фермера с печным дымком, ветряная мельница с вращающимися лопастями, сеновал и курятник.

## 📦 Что заливать на GitHub

Для публикации проекта на GitHub и запуска бесплатного сайта через **GitHub Pages** в репозиторий нужны следующие файлы:

```text
svinolov/
├── .gitignore          # Исключения временных файлов ОС и редакторов
├── index.html          # Главная точка входа (веб-страница игры)
├── style.css           # Таблица стилей игры и интерфейса
├── js/                 # Каталог скриптов логики
│   ├── game.js         # Игровой цикл, мир, деревня, камера и миникарта
│   ├── helper.js       # Автономный напарник-ловец
│   ├── pig.js          # Свиньи, блуждание, паника и Большая свинья
│   ├── player.js       # Фермер, движение WASD, кулдаун и сачок
│   ├── shop.js         # Магазин улучшений и наём напарников
│   ├── storage.js      # Сохранение в localStorage
│   └── ui.js           # Звуки Web Audio API, интерфейс и окна
├── log_dev.md          # Журнал разработки
├── memory.md           # Архитектурная память проекта
└── README.md           # Документация проекта
```

> **Важно:** Все эти файлы должны быть в корне репозитория (чтобы `index.html` лежал в корневой папке проекта).

## 🐙 Пошаговая инструкция: как выложить на GitHub и включить игру в сети

1. **Инициализируйте git** (если ещё не сделано):
   ```bash
   cd C:\Users\user\.gemini\antigravity\scratch\svinolov
   git init
   git add .
   git commit -m "Релиз игры Свинолов: магазин, напарники, большая свинья и расширенная карта"
   ```

2. **Создайте репозиторий на GitHub**:
   - Перейдите на [github.com/new](https://github.com/new).
   - Задайте имя репозитория, например: `svinolov` (или `pig-catcher`).
   - Сделайте репозиторий **Public** (публичным).
   - Не добавляйте шаблонные README, .gitignore или лицензию (они уже созданы локально).
   - Нажмите кнопку **Create repository**.

3. **Свяжите локальный репозиторий с GitHub и отправьте код**:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/svinolov.git
   git branch -M main
   git push -u origin main
   ```

4. **Включите бесплатный запуск игры в браузере (GitHub Pages)**:
   - В вашем репозитории на GitHub перейдите во вкладку **Settings** (Настройки).
   - В левом меню нажмите **Pages**.
   - В блоке **Build and deployment** выберите источник **Deploy from a branch**.
   - В поле ветки выберите **main**, папку оставьте **/ (root)** и нажмите **Save**.
   - Через 1–2 минуты ваша игра станет доступна всему миру по ссылке вида:  
     `https://ВАШ_ЛОГИН.github.io/svinolov/`
