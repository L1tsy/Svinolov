# Memory: «Свинолов» v2.1

Техническая архитектурная память для разработчиков. Пользовательское руководство — в `README.md`.

## Краткое описание
«Свинолов» v2.1 — браузерная аркадная тайкун-игра на чистом HTML5 Canvas 2D и ванильном JavaScript. Игра работает без сборщиков и внешних npm-пакетов, открывается по `file://` двойным кликом и полностью адаптирована для хостинга на бесплатном GitHub Pages. В версию 2.1 включены:
1. **Кооперативный режим на двоих**: как локально на одном экране (WASD + Стрелки с динамической камерой), так и по сети на двух разных устройствах через P2P WebRTC (PeerJS) с подключением по короткому коду комнаты или ссылке `?join=CODE`.
2. **Два персональных амбара (Dual Barns)**: Красный амбар №1 (западная база Игрока 1 / Хоста) и Бирюзовый амбар №2 (восточная база Игрока 2 / Гостя).
3. **Адаптивный умный ИИ свиней (Smart Pig AI)**: масштабирование интеллекта (IQ) от дней и престижей, стайная тревога (`pack alarm`), резкие увороты и виражи (`jinking`), использование укрытий (кусты, стога сена), грязевая тактика и панический спринт со шкалой выносливости.
4. **Прокачка напарников и пса Бобика**: 4 новых улучшения команды (скорость, радиус сачка, обзор/реакция, сила лая).
5. **Стартовый капитал престижа**: начисление стартовых монет при продаже фермы по формуле `prestigeStartingCoins(p)`.
6. **Лидерборд (Топ игроков)**: интерактивный селектор 7 критериев рейтинга, 12 колоритных фермерских соперников с динамическим ростом статов и личная карточка игрока.

## Баланс и формулы (CONFIG в `js/config.js`)

### 1. Стартовый капитал престижа
```javascript
function prestigeStartingCoins(prestige) {
    const p = Math.max(0, Math.floor(Number(prestige) || 0));
    return p > 0 ? (CONFIG.PRESTIGE_START_BASE + CONFIG.PRESTIGE_START_STEP * p) : 0;
}
// PRESTIGE_START_BASE = 50, PRESTIGE_START_STEP = 50
// 0 престиж: 0 монет
// 1 престиж: 100 монет
// 2 престиж: 150 монет
// 3 престиж: 200 монет
```

### 2. Прокачка напарников (`HELPER_UPGRADES`)
- `helper_speed` («🥾 Быстрые ноги»): макс. 5 ур., база 35, множитель 1.6, эффект: `+15%` к скорости за уровень.
- `helper_radius` («🕸️ Большие сачки»): макс. 5 ур., база 40, множитель 1.6, эффект: `+15%` к радиусу действия сачка за уровень.
- `helper_vision` («👀 Чуткий взор»): макс. 4 ур., база 50, множитель 1.65, эффект: `+25%` к радиусу обнаружения свиней и ускорение переключения целей.
- `dog_power` («🐕 Грозный лай»): макс. 5 ур., база 45, множитель 1.6, эффект: радиус лая `+20%`, длительность испуга/замедления свиней `+(уровень * 0.7)` сек.

### 3. Интеллект свиней (Smart Pig AI)
- Формула IQ:
  ```javascript
  getIntelligence(g) {
      const day = g.day || 1;
      const prestige = (g.save && g.save.prestige) || 0;
      let iq = 0.12 + Math.min(1.2, (day - 1) * 0.045) + Math.min(0.6, prestige * 0.15);
      // Модификаторы видов:
      // ninja: +0.35, gold: +0.28, runner: +0.20, mud: +0.15, boss: +0.25, piglet: -0.06
      return Math.max(0.1, iq);
  }
  ```
- **Стайная тревога (`triggerPackAlarm`)**: радиус тревоги `alarmRadius = 140 + iq * 70` (до 260px). Завизжавшая свинья активирует панику у всех свиней в этом радиусе.
- **Виражи (`jinking`)**: при дистанции до угрозы `< 150px` или при совершении игроком рывка свинья выполняет боковой срез под углом до 90°.
- **Спринт-рывок**: при зажатии в угол или рывке ловца свинья сжигает шкалу стамины (`sprintBurstT = 0.45с`, скорость x1.62).

## Кооперативный режим и Dual Barns

### Генерация карты (`World.buildCoop`)
- Габариты мира увеличены на 20% по ширине и 15% по высоте.
- Двойные амбары:
  - `barn1`: Западная база (Фермер P1, классический красный амбар).
  - `barn2`: Восточная база (Фермерша P2, бирюзовый амбар).
  - Свиньи игрока направляются в его домашний амбар через `world.getDoorForPlayer(p)`.
- Разделительная река с кубическими кривыми Безье и 2–3 деревянных пешеходных мостика.
- Метод `isOnBridge(x, y)`: если сущность находится в прямоугольнике настила мостика, коллизии воды исключаются из проверок `resolve()`, `avoid()` и `isFree()`.
- Интерактивные объекты:
  - Пугало Кузя: взмах или рывок вблизи раскачивает пугало и пугает свиней в радиусе 170px в сторону коридоров.
  - Фермерский колокол: взмах сачком звонит в колокол, разворачивая стадо звуковой волной.

### Игрок 1 и Игрок 2 (`Player`)
- **P1 (Фермер)**: синий комбинезон `#3b82f6`, кремовая рубашка `#f4f1e8`, соломенная шляпа (или купленная), голубой шлейф рывка `#7dd3fc`.
- **P2 (Фермерша)**: бирюзовый комбинезон `#0d9488`, лимонная рубашка `#fef08a`, каштановые косички с ленточками, шляпка `daisy` или бандана `bandana`, мятный шлейф `#2dd4bf`.
- **Локальное управление (на одном ПК)**:
  - P1: `WASD` бег, `Space` взмах, `Left Shift` рывок.
  - P2: `Стрелки` бег, `Enter` / `Slash` взмах, `Right Shift` / `Numpad 0` рывок.
- **Кооп-взаимодействия**:
  - Дуга синергии: при дистанции `< 170px` между игроками возникает золотая силовая линия, радиус взмаха сачка обоих игроков возрастает на `+20%`.
  - «Дай пять!»: касание оглушенного напарника мгновенно снимает стан и дает ускорение `+35%` на 1.3 секунды.
  - Кооп-комбо: поочередные поимки свиней обоими игроками накапливают кооп-комбо с командным бонусом монет `coopCatchCombo * 3`.
  - Зажатие в клещи (Pin Stun): одновременное приближение P1 и P2 к кабану или боссу с противоположных сторон повергает врага в оглушение на 3.0 секунды.

## Онлайн-мультиплеер P2P (WebRTC через PeerJS)

- **Отсутствие бэкенда**: хостинг на GitHub Pages не требует выделенного сервера Node.js. Сигналинг осуществляется через бесплатные открытые STUN-серверы Google и Twilio.
- **Код комнаты**: 4-значный номер (например, `4821`), генерируемый хостом, либо прямая ссылка с параметром URL `?join=4821`.
- **Роли**:
  - **Хост (P1 Фермер)**: авторитарная сторона. Симулирует перемещение и ИИ свиней, таймер дня, бонусы и рассылает снимки состояния (`P2P World Snapshot`) с частотой 25 Гц. Камера хоста зафиксирована на P1. Домашний амбар — Красный №1.
  - **Гость (P2 Фермерша)**: клиентская сторона. Управляет своим персонажем с привычной раскладки WASD или экранного джойстика, камера зафиксирована на P2. Отправляет команды ввода (`Input Packet`) с частотой 30 Гц. Домашний амбар — Бирюзовый №2.

## Лидерборд (Топ игроков)

- Константа `LEADERBOARD_CRITERIA` в `js/ui.js` содержит 7 критериев:
  1. `prestige`: По числу престижей.
  2. `totalCoins`: По суммарно заработанным деньгам (all-time).
  3. `coins`: По текущему балансу монет.
  4. `bestDay`: По максимальному пройденному дню.
  5. `totalPigs`: По общему числу пойманных свиней.
  6. `bestCombo`: По лучшему зафиксированному комбо.
  7. `perfectDays`: По дням, закрытым на 3 звезды.
- 12 виртуальных соперников масштабируют свои показатели в зависимости от прогресса игрока: Дед Митяй, Фермерша Глаша, Дядя Вася с мельницы, Ковбой Боб, Баба Дуся, Хитрый Федот, Свинопас Семён, Пасечник Лукич, Агроном Степан, Викинг Олаф, Баронесса Белла, Ниндзя Ли.
- Карточка игрока отображает текущее место (#1–#13), медаль (🥇, 🥈, 🥉) и аватарку в надетой шляпе.
