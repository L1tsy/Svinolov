# Memory: Проект «Свинолов»

## Краткое описание
2D-игра в браузере (HTML5 Canvas + ванильный JS, CSS) в жанре тайкун/кликер с поддержкой мыши и тач-управления на смартфонах.
Игрок управляет ловлей сбежавших свиней на ферме. За каждую пойманную свинью даётся монета. Игра разбита на дни: каждый новый день сбегает больше свиней. Прогресс сохраняется в `localStorage`. Игра запускается простым открытием `index.html` (без сборщиков и серверных зависимостей, чистый vanilla JS без ES-модулей для работы по протоколу `file://`).

## Архитектура и структура файлов
Проект располагается в папке: `C:\Users\user\.gemini\antigravity\scratch\svinolov`

- `index.html` — корневой HTML-файл с канвасом, HUD (с кнопками Магазина и напарника), подсказками, окном магазина, экранным D-Pad и подключением скриптов.
- `style.css` — стили для адаптивного холста, HUD, модальных окон завершения дня и магазина, подсказок и виртуального D-Pad контроллера.
- `js/storage.js` — модуль `StorageManager`: сохранение и загрузка прогресса (`coins`, `day`, `totalPigsCaught`, `upgrades: { speedLevel, radiusLevel, cooldownLevel, helpersCount }`) в `localStorage`.
- `js/shop.js` — класс `Shop`: каталог улучшений (сапоги-скороходы, большой сачок, ловкие руки) и прогрессивный наём напарников с рендером карточек и покупкой.
- `js/player.js` — класс `Player`: фермер с поддержкой WASD-управления, вектора непрерывного перемещения, взмаха сачком `swing()`, коллизий со всеми домами деревни, кружка зоны ловли и кулдауна с индикатором перезарядки.
- `js/helper.js` — класс `Helper`: автономные напарники-ловцы с уникальными цветами комбинезонов, собственный ИИ поиска свиней, анимация сачка и помощь в удержании Большой свиньи.
- `js/pig.js` — класс `Pig`: свинки с процедурной отрисовкой, ИИ блуждания и паники, обходом препятствий и возвратом в центральный амбар. Поддержка Большой свиньи (`isBig = true`, корона, награда 10 монет, поимка вдвоем).
- `js/ui.js` — класс `UI`: управление HUD (монеты, день, свиньи, кнопка найма напарника), плавающие надписи `+1 🪙` / `+10 🪙`, модальное окно смены дня с бонусом скорости и звуки Web Audio API.
- `js/game.js` — синглтон/класс `Game` и `CONFIG`: игровой цикл `requestAnimationFrame`, виртуальная камера `camX, camY`, радар-миникарта, расширенная карта с 20 дня (сад, тыквы, пруд), центральный амбар `drawBarn`, процедурная деревня.
- `.gitignore` — файл исключений для чистоты репозитория GitHub.
- `log_dev.md` — подробный журнал каждого действия и решения.
- `README.md` — пользовательская документация игры, инструкция по запуску, управление, список возможностей.
- `memory.md` — техническая память проекта с архитектурой и балансом.

## Текущий статус: Магазин улучшений, масштабируемые напарники (50, 75, 100...) и расширенная карта с камерой (20+ день)
- Магазин улучшений: доступен по кнопке `🛒 Магазин` в HUD. Прокачка сапог-скороходов (скорость), большого сачка (радиус) и ловких рук (кулдаун).
- Прогрессивный найм напарников:
  - 1-й напарник: с 10 дня за **50** монет;
  - 2-й напарник: с 20 дня за **75** монет;
  - 3-й напарник: с 30 дня за **100** монет;
  - Формула: стоимость `50 + 25 * count`, день `10 + 10 * count`. Все напарники параллельно ловят свиней.
- Большая свинья: появляется с 15 дня, приносит 10 монет. Поймать можно ТОЛЬКО вдвоём (игрок + напарник рядом).
- Расширение карты деревни с 20-го дня:
  - Территория увеличивается в 1.6 раза, включается виртуальная плавная камера;
  - Новые зоны: 🍎 Яблоневый сад, 🎃 Огород с тыквами, 🦆 Пруд с кувшинками;
  - В углу экрана работает удобный радар-миникарта с отображением всех свиней, напарников и амбара в реальном времени.

## Настройки баланса (CONFIG в js/game.js)
- `CONFIG.BASE_PIGS_COUNT = 2` — начальное число свиней в день 1.
- `CONFIG.HELPER_BASE_DAY = 10` — день доступности 1-го напарника.
- `CONFIG.HELPER_STEP_DAY = 10` — шаг открытия следующих напарников (дни 20, 30...).
- `CONFIG.HELPER_BASE_COST = 50` — стоимость 1-го напарника (50 монет).
- `CONFIG.HELPER_STEP_COST = 25` — прирост стоимости (+25 монет).
- `CONFIG.BIG_PIG_START_DAY = 15` — день появления Большой свиньи.
- `CONFIG.BIG_PIG_REWARD = 10` — награда за Большую свинью (10 монет).
- `CONFIG.EXPANDED_WORLD_DAY = 20` — день расширения карты деревни.
- `CONFIG.SPEED_BONUS_BASE_TIME = 14` — базовое время для бонуса (сек).
- `CONFIG.SPEED_BONUS_PER_PIG = 3.5` — добавочное время на свинью (сек).
- `CONFIG.SPEED_BONUS_COINS = 3` — бонус за быстрый улов (3 монеты).
- `CONFIG.PLAYER_SPEED = 235` — базовая скорость фермера.
- `CONFIG.CATCH_RADIUS = 52` — базовый радиус кружка действия сачка.
- `CONFIG.CATCH_COOLDOWN = 1.0` — базовый кулдаун сачка (1 сек).
